[P28] 1. Abstract
[P29] The rapidly evolving landscape of Artificial Intelligence (AI) and Large Language Models (LLMs) presents unprecedented opportunities to transform conventional web applications and automated workplace workflows. Traditional database management systems and email client interfaces often suffer from complex queries, steep learning curves, and manual operational overhead. The AI-Powered MERN SQL Agent & Gmail Auto-Reply Bot bridges this gap by creating an intelligent, unified system that combines natural language database management with automated, human-in-the-loop email communication.
[P30] The primary objective of this project is twofold. First, it implements a full-stack MERN application (MySQL, Express.js, React.js, and Node.js) featuring a powerful AI SQL Agent powered by Google Gemini AI. By utilizing advanced function calling and agentic tool execution, non-technical users can interact with relational databases using plain natural language (e.g., “Add a student named Alice with 90 marks in CS course” or “Show all products priced above 500”). The system translates intent into secure SQL execution, updates database records dynamically, and generates professional PDF summaries on demand.
[P31] Second, the platform integrates a multi-channel Telegram Bot & Gmail Assistant. Utilizing Google OAuth 2.0 and the official Gmail REST API, the Telegram bot monitors unread inbox messages, analyzes message context using Gemini AI, and auto-generates structured reply drafts. To guarantee safety and privacy, the bot employs a Human-In-The-Loop approval flow featuring interactive inline Telegram buttons (✅ Send Reply / ❌ Skip), allowing users to review, edit, or send emails seamlessly directly from their Telegram chat.

[P34] 2.1 Project Overview
[P35] Modern enterprise operations and academic management require efficient data retrieval, accurate record updates, and prompt communication. Traditional relational database management interfaces (such as phpMyAdmin or raw SQL command line tools) demand explicit knowledge of Structured Query Language (SQL). [P98] The backend automatically initializes connection pooling and ensures required MySQL database tables exist upon server boot:
[P99] const mysql = require('mysql2');
require('dotenv').config();

const db = mysql.createConnection({
  host: process.env.DB_HOST,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME
});

db.connect((err) => {
  if (err) { console.error('❌ MySQL Connection Failed:', err.message); return; }
  console.log('✅ MySQL Connected!');
  db.query(`CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100), email VARCHAR(100),
    course VARCHAR(100), marks INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  )`);
});
module.exports = db;
[P100] 6.2 Telegram Bot & Gmail AI Reply Handler (`gmail-bot/bot.js`)
[P101] The Telegram bot inspects unread Gmail messages, requests Gemini AI to generate contextual reply drafts, and renders interactive review keyboards:
[P102] bot.onText(/\/check/, async (msg) => {
  const chatId = msg.chat.id;
  const emails = await getUnreadEmails();
  for (const email of emails) {
    const aiReply = await generateReply(email.from, email.subject, email.snippet);
    pendingEmails[email.id] = { ...email, aiReply };
    await bot.sendMessage(chatId,
      `📩 *New Email*\n👤 From: ${email.from}\n📌 Subject: ${email.subject}\n\n🤖 *AI Draft:*\n${aiReply}`,
      { parse_mode: 'Markdown', reply_markup: {
          inline_keyboard: [[
            { text: '✅ Send Reply', callback_data: `send_${email.id}` },
            { text: '❌ Skip', callback_data: `skip_${email.id}` }
          ]]
      }}
    );
  }
});
